# Streamlit MovieLens Recommender

Interactive movie recommendation app built with Streamlit. Combines collaborative filtering, content-based similarity, and genre preference weighting for personalized recommendations.

## Features
- Genre selection + liked movies input
- Hybrid recommender: CF + content + genre weights
- Adjustable model weights via sliders
- Built on MovieLens small dataset

## Live Demo
🚀 Deployed on Streamlit Community Cloud:  
https://pankajsyadav-streamlit-app.streamlit.app

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
